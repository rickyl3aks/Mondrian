# Mondrian

A small p5.js sketch that draws a geometric composition inspired by Piet Mondrian, using a limited palette of red, blue, yellow, white, and black outlines.

## Run

Open `index.html` in a web browser. The page loads the local p5.js library from `p5.min.js` and runs the drawing in `sketch.js`. No install or build step is required.

## Project files

- `index.html` — page entry point and script references.
- `sketch.js` — creates the 800 × 800 canvas and draws the composition.
- `p5.min.js` — bundled p5.js library.
